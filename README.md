# 🏥 Which U.S. Hospitals Are Losing Efficiency in Supply Chain & Patient Care?
### Hospital Performance Analysis using CMS Hospital Compare Data
---
## 📌 Business Problem
U.S. hospital networks face rising operational costs while patient satisfaction scores remain uneven across regions. This analysis uses publicly available CMS data to identify performance patterns, benchmark hospitals by state and ownership type, and surface insights that operations directors can act on.
## 👥 Stakeholder
Hospital Operations Director / CFO at a multi-facility U.S. hospital network
## 🛠 Tools Used
- **Excel** — data cleaning, audit trail, exploratory pivot analysis
- **MySQL** — relational data modeling, analytical queries
- **Power BI** — interactive dashboard for stakeholder reporting
